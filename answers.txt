Q1: Why might we consider using Git?

Answer: Git helps us track changes to files, manage different versions of a project,
collaborate with others, and recover previous versions if something goes wrong.

Q2: What field could data science be applied to? Give an Example.

Answer: Data science can be applied to healthcare.
For example, hospitals can analyze patient data to identify patterns
and help predict which patients may be at higher risk for certain diseases.

Q3: What is the difference between Merging and Rebasing?

Answer: Merging combines changes from two branches and usually creates a merge commit,
while rebasing moves or replays commits from one branch onto another branch to
create a more linear commit history.
